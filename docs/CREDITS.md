# Créditos

## Tecnologías y Bibliotecas

Este proyecto fue desarrollado utilizando las siguientes tecnologías:

- **React 19** - Biblioteca de UI
- **Vite** - Build tool y dev server
- **TypeScript** - Tipos estáticos
- **React Router** - Navegación (si aplica)
- **Dexie.js** - Wrapper para IndexedDB
- **Supabase** - Backend as a Service (Auth, PostgreSQL, RLS)
- **Vite PWA Plugin** - Progressive Web App capabilities
- **React Icons** - Conjunto de iconos
- **clsx** - Utilidad para classes condicionales
- **date-fns** - Manipulación de fechas

## Servicios Externos

- **Cloudflare R2** - Almacenamiento de objetos para fotos familiares
- **npm** - Gestor de paquetes

## Design y UX

- **Material Design** - Principios de diseño
- **Vite Default Theme** - Estil base

## Proyecto

**ARBOL-GEN-PRO** - Aplicación de árbol genealógico familiar colaborativo

- Propósito: Registrar varias generaciones de árboles genealógicos familiares
- Características: Offline-First, PWA, gestión de fotos, colaboración
- Licencia: MIT
