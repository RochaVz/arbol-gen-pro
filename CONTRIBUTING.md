# Contributing

Thank you for considering contributing to ARBOL-GEN-PRO! This project is built with ❤️ for families to preserve their genealogy trees.

## Ways to Contribute

### Reporting Issues

- Use the [issue tracker](https://github.com/your-org/arbol-gen-pro/issues) to report bugs or request features
- Include clear steps to reproduce, expected vs actual behavior, and your environment

### Development

1. Fork the repository
2. Create a branch: `git checkout -b feature/foo-bar`
3. Make your changes
4. Run `npm run lint` and `npm run build` to verify
5. Commit: `git commit -m "Add foo bar feature"`
6. Push: `git push origin feature/foo-bar`
7. Submit a Pull Request

### Documentation

- Improve or translate the documentation in the `docs/` folder
- Help add examples and tutorials

### Financial

- Consider [sponsoring](https://github.com/sponsors) the project

## Development Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Lint code
npm run lint

# Run tests
npm run test

# Build for production
npm run build
```

## Project Conventions

- Follow the existing code style
- Write clear commit messages
- Update documentation when adding features
- Test your changes thoroughly

## Thank You!

Your contribution, no matter how small, helps make ARBOL-GEN-PRO better for everyone.
